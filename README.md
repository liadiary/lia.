# Flourish Review Hub

面向达人内容合作的脚本与视频审核工作台。

当前版本支持：

- 每次品牌合作独立建项目
- 脚本初审、脚本二审、视频一审和视频二审
- 阶段独立模型链接、Brief 与项目补充要求
- AI 审核草稿、人工编辑与确认
- 倒叙保存审核历史
- 一键复制飞书格式
- 浏览器本地保存

飞书在线文档读取需要后续配置飞书应用授权；当前版本保存链接和权限状态，不会绕过文档访问权限。

## 使用

直接双击 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。数据保存在当前浏览器的 `localStorage` 中。
